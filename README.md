# StudyForge AI

A browser-based studying app where students can add or upload notes, slide text, documents, and source summaries. The app turns those materials into generated flashcards, a timed study-session plan, an AI voice-teacher mini lesson, and quizzes/practice-test questions.

## Features

- Add notes, slide shows, documents, and source links manually.
- Upload text-based files for quick importing.
- Generate keyword-based flashcards from all loaded materials.
- Build a timed study session with warm-up, flashcards, teacher lesson, and quiz phases.
- Play an AI-style voice teacher lesson using the browser Web Speech API.
- Take auto-generated study quizzes and practice tests with scoring and explanations.

## Run locally

```bash
npm run start
```

Then open <http://localhost:4173>.

## Test

```bash
npm test
```
